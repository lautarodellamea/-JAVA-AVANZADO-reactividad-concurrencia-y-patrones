# Java Avanzado: apuntes

Apuntes propios del curso de Java avanzado, pensados para estudiar de forma autónoma.

## Cómo usar este repositorio

1. Seguí las secciones en orden.
2. En cada clase: leé `apuntes.md` y después corré el código que está en la misma carpeta.
3. Hacé los ejercicios antes de mirar las soluciones.

Todo vive bajo `src/main/java/com/empresa/project/`: cada sección es un paquete y cada clase, un subpaquete con su código y sus apuntes.
